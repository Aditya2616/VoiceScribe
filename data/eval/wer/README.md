# WER clips

Twelve utterances from LibriSpeech test-clean (4 speakers, 3 each), selected by `scripts/fetch_librispeech.py`.
Source: https://www.openslr.org/12, licence CC-BY-4.0. Panayotov, Chen, Povey, Khudanpur, "LibriSpeech: an ASR corpus
based on public domain audio books", ICASSP 2015. `refs.tsv` holds the official reference transcripts.
This is read speech, not conversational meeting speech.
